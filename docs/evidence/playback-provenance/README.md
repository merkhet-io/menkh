# Playback exposure evidence

`job.json` is the actual 25 µm, 325-operation pocket input with all-frames
provenance. `measurements.json` retains all eight runs: one warm-up and three
measurements per scope, using identical initial material and output settings.
It records individual wall/cutting/provenance phase times, allocated index
capacity, process peak RSS and final-state hashes. All final-state hashes match.
`environment.json` identifies the compiler, hardware, source and binary.

Reproduce:

```sh
./zig build -Doptimize=ReleaseFast
zig-out/bin/menkh job docs/evidence/playback-provenance/job.json --out out/playback-pocket
./scripts/build-viewer.sh
zig-out/bin/menkh-viewer out/playback-pocket/voxel-animation.json --frame 160 --color-operation
zig-out/bin/menkh-viewer out/playback-pocket/voxel-animation.json --verify-history out/playback-pocket/replay.json
zig-out/bin/menkh-viewer out/playback-pocket/voxel-animation.json --frame 160 --color-operation --hide-tool --render-bench out/playback-pocket/render.json
```

For the comparison, change only `provenance_scope` to `final_surface` in a copy of
the input. Repeat each job four times from initial stock, discarding the first
run for summary statistics. The CLI rebuilds initial stock for every invocation.
Use separate output directories for each scope. Rendering is separate from job
measurements, and GPU command time is not interactive frame rate.

`replay.json` records byte-exact native forward/backward/forward replay of the full
pocket. `render-colored.json` and `render-material.json` contain separate offscreen
samples at frame 160; load/seek values are single observations, not repeated
latency benchmarks. Shared viewer buffers totaled 72,970,288 bytes, not process
RSS. `frame-160.png` was actually rendered and inspected. The picker at this frame
reported `Layer 1 / 059`, operation 59, tool 0 at approximately
(-2.5506, 2.6262, 6.0000) mm.

`validation.json` covers the independent small-grid, every-frame chronology
oracle generated by `python3 scripts/test-playback-provenance.py`. Its complete
removal final frame deliberately has no surface labels, while earlier frames
retain 1,163 historical neighbor labels. The native and portable reader tests
seek forward/backward/forward and reject labels from future operations.
